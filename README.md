# المستشار السيبراني (@at_scy) - Portfolio

هذا المشروع هو موقع شخصي مبني بـ HTML, CSS, JavaScript فقط (Vanilla)، ومصمم ليكون خفيفاً وسهلاً للتعديل من الهاتف المحمول، وجاهزاً للنشر المجاني عبر GitHub Pages.

## هيكل الملفات
- `index.html`: البنية الأساسية للموقع (يحتوي على النصوص العربية والإنجليزية باستخدام خصائص `data-ar` و `data-en`).
- `style.css`: التصميم بنمط Cyberpunk وشاشات الطرفية.
- `script.js`: أكواد التفاعل، تبديل اللغة، وتوليد المحتوى.
- `config.js`: **الملف الأهم لك**. من هنا يمكنك إضافة روابط التواصل الخاصة بك، وإخفاء أو إظهار الخدمات التي تقدمها حالياً.

## كيفية التعديل
افتح ملف `config.js` وأضف روابطك بين علامتي التنصيص `""`. إذا أردت إخفاء خدمة، قم بتغيير `true` إلى `false`.

لتغيير النصوص الأساسية أو إضافة مشاريع جديدة، افتح `index.html` وابحث عن النص، ستجد أنه مكتوب هكذا:
`<h3 data-ar="بالعربي" data-en="In English">بالعربي</h3>`
قم بتغيير النص في الأماكن الثلاثة ليتم التحديث في اللغتين.
